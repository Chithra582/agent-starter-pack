# Template Scaffolding

## Overview
Generates production-grade starter codebases with built-in dependency management, testing, linting, and containerization.

## When to Use
- When initiating a new Google Cloud GenAI agent project from scratch.
- When selecting between ADK (Python, TS, Go, Java), LangGraph, or Multimodal Live agent architectures.
- When generating frontend integrations (Streamlit, React, or chat interfaces).

## Core Capabilities
1. **Interactive & Parametric Generation**: CLI-guided or non-interactive prompt flags for deterministic reproduction.
2. **Polyglot Runtime Support**: Generates idiomatic code in Python, TypeScript, Go, or Java.
3. **Batteries Included**: Includes pre-configured linters (`ruff`), type checkers (`pyright`/`ty`), and testing frameworks (`pytest`).
